# 📚 My Backlog | تراكماتي

> **Distraction-Free Study Catch-Up Engine — لمّ المواد المتراكمة بدون تشتيت**

🔗 **Live Demo:** [backlog-tracker177.vercel.app](https://backlog-tracker177.vercel.app/)

---

## 💡 Idea & Philosophy | فكرة المشروع

Unlike traditional To-Do lists that make it easy to delete tasks and procrastinate, **My Backlog (تراكماتي)** is built specifically for students (High School, Engineering, Medicine, etc.) to catch up on missed lectures and practice sheets with psychological accountability:

* **Subject-Level Control:** Add or remove your subjects freely on the main dashboard.
* **Zero-Delete Inside Subjects:** Once you add a missed lecture or practice sheet inside a subject, **there is no delete button**. The only way to clear it is to study it and check it off!
* **"No Backlog" Reward State:** Subjects with zero pending items automatically display a calming **`No Backlog / لا تراكمات`** badge.

---

## ✨ Features | المميزات

* **Bilingual Support (AR / EN):** Instant switching between Arabic (`RTL`) and English (`LTR`) with adaptive typography (`Cairo` & `Plus Jakarta Sans`).
* **Warm Light & Dark Modes:** Carefully crafted earthy color palette designed to reduce eye strain during late-night study sessions.
* **Separate Tracking Per Subject:** Dedicated sections for **Accumulated Lectures (المحاضرات المتراكمة)** and **Accumulated Practice (الحل المتراكم)**.
* **100% Client-Side & Private:** Zero sign-up required. All data, language preferences, and theme settings are saved automatically in `localStorage`.
* **Responsive SPA Experience:** Smooth single-page transitions between the subjects dashboard and individual subject workspaces on both desktop and mobile.

## 🚀 Getting Started | التشغيل محلياً

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/my-backlog.git
   ```
2. Open `index.html` directly in your browser (or use Live Server in VS Code).
3. Ensure `og-image.jpg` and `favicon.svg` are in the root directory alongside `index.html` when deploying.
